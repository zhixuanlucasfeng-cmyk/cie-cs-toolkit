# DryRun Stabilization Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Make DryRun's 235-test result truthful in a real browser and enforce it before deployment.

**Architecture:** Keep the production application as one dependency-free static HTML file. Add a development-only Playwright harness around the public `?selftest=1` route, defer the inline report until UI initialization is complete, and run core plus browser verification in GitHub Actions.

**Tech Stack:** Static HTML/CSS/JavaScript, Node.js 22, Playwright Chromium, GitHub Actions

**Spec:** `docs/superpowers/specs/2026-09-23-dryrun-stabilization-design.md`

## Global Constraints

- Preserve `dryrun.store.v3`, all legacy migration keys, snapshots, import/export, and learner/course ownership.
- Do not change interpreter semantics, question content, marking rules, syllabus coverage, or visual design.
- Production remains a single static page with no runtime package or network dependency.
- Do not push or deploy during this plan.

- [x] **Step 1: Add a browser test that describes the required behavior**

test('the public self-test route passes every test in a real browser', async ({ page }) => {
